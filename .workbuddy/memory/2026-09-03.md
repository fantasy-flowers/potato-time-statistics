## 修复 BarChart 崩溃（COMException 0x800F1000）
- 崩溃报错文案「没有检测到已安装的组件」是误导：0x800F1000 是 XAML 错误码与 SPAPI_E_ERROR_NOT_INSTALLED 撞号，真实含义为 "Element is already the child of another element"（Raymond Chen 博客有专文解释）。
- 根因：`BarChart._plotArea`（readonly Canvas）每次 `Render()` 都被 Add 进新建的 plotGrid，而旧 plotGrid 仍是其父级；SizeChanged → Render 重入即崩溃（首次渲染正常，窗口尺寸一变就崩）。
- 修复 1（BarChart.cs）：plotGrid 改为 readonly `_plotGrid` 字段，构造函数里一次性挂 `_plotArea`，Render 复用。
- 修复 2（StatsPage.cs，同类隐患）：`BuildPage()` 在 ActualThemeChanged（主题切换）时重入，`Content=null` 不会解除 `_playtimeView`/`_gameStatsView` 与旧 body 的父子关系，再 Add 会抛同样异常；新增 `DetachFromParent()` 辅助，挂载前先摘除。
- DonutChart 与两个 Prefab（StdAccountPanel/StdSetting）审查过，无此问题。
- 编译通过（Release）；csproj 后置 `powershell` 打包步骤在 Git Bash 下 9009，改用 System32 bsdtar `tar -a -cf` 重建 `artifacts/plugin.pvnplugin.zip`（28 条目，结构与 Compress-Archive 一致）。
- 经验已写入 AGENTS.md Project Facts。

## 修复窗口放大时界面右移 + 两处图表布局问题（18:30）
- 用户反馈：窗口变大时游戏时长统计界面组件右移。该问题在崩溃修复后才暴露（此前一 resize 就崩）。
- 根因 1（右移主因，StatsPage）：`Grid { MaxWidth=1400, Stretch }` 直接作为 ScrollViewer 内容，窗口超过 ~1448px 后 Stretch 被 MaxWidth 截断时按"居中"排列，窗口越大内容整体越往右滑。修复：容器撑满视口 + `ColumnDefinition { Star, MaxWidth=1400 } + [Auto]` 双列，内容靠左封顶。
- 根因 2（BarChart）：X 轴标签没有按柱形槽位偏移（初始提交就缺 `Margin.Left = slotWidth*i`），7 个标签全堆在绘图区左边缘重叠。
- 根因 3（PlaytimeStatsView.BuildTrendRow）：进度条填充 `Width = barPercent` 把 0-100 百分数当像素用，改为星列百分比（percent / 100-percent Star 列）。
- Release 编译通过，bsdtar 重新打包 plugin.pvnplugin.zip。经验已补进 AGENTS.md。
